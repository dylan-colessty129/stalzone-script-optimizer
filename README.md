## What It Does

STALZONE Artifact Optimizer is a web utility for examining artifact setups in STALZONE. It allows players to test possible combinations, compare the resulting builds, and focus the search on the stats that matter most for a particular setup.

Its reference data comes from the official STALZONE build calculator. Open the live demo to experiment with artifact layouts, inspect the calculated outcomes, and adjust a build toward defined stat priorities.

## Frequently Asked Questions

No. The web demo operates through a browser and does not require the game to be installed.

### How does the optimizer choose combinations?

It checks the available artifact arrangements against the desired stats specified for the build, then returns combinations that best correspond to those priorities.

### Are target stats configurable?

Yes. You select the stats that should guide the optimization before reviewing the calculated alternatives.

### What is the source of the reference data?

The tool uses data from the official STALZONE build calculator. The results therefore depend on the coverage and accuracy of that source.

Place the project files in the same directory so the HTML interface can locate its related assets. The directory can have any name, provided the original file structure remains intact.
